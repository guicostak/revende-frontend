## Como usar uma skill

As skills não estão instaladas neste projeto: são material de consulta em disco. Ao
enfrentar um problema coberto por uma delas, leia o `SKILL.md` correspondente e traga
para cá **só o que virar regra verificável** deste repositório. A rede é destilado, não
cópia.
